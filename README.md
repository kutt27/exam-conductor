# AI Enabled Exam Software

A soft spoken software built for conducting exams for students with auto-grading using AI. Supports both MCQs, coding, and theory questions.

## Solved problems?
- Saves the time of the exam conductor(s) by allocating the valuation to an AI assistant.
- Does not get biased under time constraints.
- Valuates every type of answer from the student's side rather than checking every approach of `n` students.

## Features
- Rubric for every coding/theory question for valuation. For example, if for a question, we can set it to look into the logic **rather** than the syntax.
- Mental test-case tracing with passed/failed execution traces and constructive feedback. 
- Random assign of MCQ question for each participant. Order of MCQ will be different for students.
- Zero-latency auto-grading of multiple-choice questions.
- Fullscreen enforcement and exit detection.
- Tab switch **and** window blur detection via `visibilitychange`.
- Disabled clipboard (cut, copy, paste) and right-click context menu.
- Comprehensive telemetry event audit trail logged for teacher review.
- Monospace interview doc editor.
- Native tab key indentation support.
- Spellcheck and autocomplete disabled for distraction-free algorithmic writing.
- Admin console. With user levels such as (ADMIN, TEACHER, STUDENT).
